Orbital is 2D astronomical gravity simulator with N-body physics.

It is made with the turtle library and its parent library tkinter.

I tried to implement OOP (Object-Oriented-Programming) elements to the project. The Orbitals are all made via python classes.

You can install the project via the Releases page.
